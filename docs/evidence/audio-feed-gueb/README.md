- Actual production code path: `src/worker/synthesis.ts` creates `GeminiTtsClient` without a model override; `src/tts/gemini.ts` chooses `gemini-3.8-flash-tts`. The separate grounded script stage defaults to `gemini-3.8-flash` with `maxOutputTokens: 4096`. There is no model env override in `src/config.ts`. Paul's exact `Gemini API error:` prefix is exclusive to the TTS HTTP error handler, not the script call. The 8192 cap therefore points to the TTS model, **not** an old text model.
- **Before:** one unsegmented TTS request contained 47,044 UTF-8 bytes of transcript (`title` plus article); model `gemini-3.8-flash-tts`, temperature `0.7`, `maxOutputTokens` unset. The original request shape was sent through `GeminiTtsClient.sendRequest` to an injected HTTP-400 API response carrying Paul's exact `The input token count exceeds the maximum number of tokens allowed (8192).` error. This is a local HTTP-response reproduction, **not** evidence the actual provider rejected this specific article.
- **After:** eight ordered TTS requests to `gemini-3.8-flash-tts`; transcript UTF-8 byte lengths `[5867,5989,5974,5834,5975,5830,5858,5706]`, all below the 6000-byte budget. Temperature `0.7` and explicit `maxOutputTokens: 16384` on each request. Paragraph and sentence boundaries are preferred before word boundaries for natural breath points. Mocked PCM is joined into one RIFF WAV; dialogue segment speaker metadata is retained and incompatible audio fails closed. The grounded script call formerly set `maxOutputTokens: 4096`, a potential ceiling for 14 research-backed turns; the request now explicitly sets `16384` on `gemini-3.8-flash` (captured and asserted by `tests/grounded_script_test.ts`). This is a capacity/configuration proof, not a demonstration that 4096 actually truncated a real provider response.
- **Documented model limits:** Google's [Gemini 3.8 Flash TTS model page](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash-tts), retrieved 2026-10-06, lists “Input token limit 8,192” and “Output token limit 16,384 (Gemini API serving limit).” Thus 16,384 does **not** exceed the published TTS output ceiling. Google's [Gemini 3.8 Flash model page](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash), retrieved 2026-10-06, lists “Output token limit 65,536”; the script's 16,384 is also within its published ceiling. Actual request acceptance for either model remains untested on this VM.
- **Token counts:** Exact provider `countTokens` results are **unavailable**: `GEMINI_API_KEY` is not set on this lane. Byte counts are not exact token counts. The 6000-byte transcript bound leaves at least 2192 token-equivalents for per-request metadata against the 8192 input cap; every token of the transcript consumes at least one UTF-8 byte, even for CJK. This is conservative arithmetic, not provider-measured usage. The error reports `estimatedInputTokens<=N (UTF-8-byte bound)` as a conservative approximation, not an API-measured count.
